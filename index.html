Strumenti Rapidi Help Desk & Risoluzione Disservizi

Script PowerShell e procedure guidate per i problemi informatici più frequenti

🖨️

Reset Spooler di Stampa Windows

Sblocca le code di stampa bloccate eliminando i file .SPL corrotti e riavviando il servizio.

Stop-Service Spooler -Force; Remove-Item C:\Windows\System32\spool\PRINTERS\* -Force; Start-Service Spooler
🌐

Svuota Cache DNS & Rinnova IP (DHCP)

Risolve problemi di connettività internet o indirizzi IP invalidi (APIPA 169.254.x.x).

ipconfig /flushdns ; ipconfig /release ; ipconfig /renew
🔑

Sblocco Account Active Directory

Sblocca gli account utente bloccati dopo 3 password errate e reimposta la password temporanea.

Unlock-ADAccount -Identity "utente.cognome" ; Set-ADAccountPassword ...
📡

Test Porta di Rete (Socket Test)

Verifica se una porta remota (es. porta RAW 9100 stampante o porta 445 file server) è aperta e risponde.

Test-NetConnection -ComputerName 192.168.1.200 -Port 9100
